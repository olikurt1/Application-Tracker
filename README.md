# Application-Tracker

** Status: Planning **

A small python tool used to track applications for placements/internships including deadlines and follow up actions. It's purpose is to provide support with my applications while also helping learn, practice and demonstrate my programming and development skills. 

## Problem 

When applying for placements it is easy to lose track of roles, deadlines and what needs attention next. This program eliminates this problem by offloading the need to remember every single application. 

## First version goals

- Add an application with a company, role, link to application, deadline and status
- View application by deadline or status
- Update application details and record next action for application
-Preserve the information after the program closes. 

## Portfolio goals

This prohect should be able to demonstrate my ability to:
- Turn a real problem into a clear program.
- Organise and validate data. 
- Save and retrieve data reliably.
- Explain and documnet my implementations.

## First verion completion requirements

- Personally able to use application
- Invalid or missing info gets a clear response
- Data is retained outside of program loop
- Others able to use the tracker to set up and use
